# 青雀 · 摸鱼版

> 一个太卜司的卜者。最低职级，工龄十余年，牌技一流。
>
> 她的哲学只有一条：工作不算争取价值，那叫劳动交换酬劳。

一个纯提示词的《崩坏：星穹铁道》青雀。不是更萌的青雀，是**算得清、懒得动、心里有一张牌桌**的那一个。

## 只有手机

→ **[prompt/](prompt/)**

贴 `01 档案`，再贴 `02 状态卡`（第一次空着），选一个开场，聊。不需要电脑。

## 有电脑

→ **[home/](home/)**

给她一间小院：一张牌桌、一盏常年关着的灯、一杯凉茶、一本牌谱。需要 Python 3，不需要装库。

```
python feibao.py 安家 "D:\青雀的家"
```

## 区别

| | 手机版 | 电脑版 |
|---|---|---|
| 记忆 | 状态卡，你贴 | 牌谱，自己存 |
| 时间 | 你写 | 窗，真的日期 |
| 关系 | 一级一级 | 好感落盘，不会跳 |
| 房间 | 无 | 灯、茶、床，会留痕迹 |
| 门槛 | 无 | Python 3 |

## 她长什么样

不是指脸，指结构：

- **里屋是一张牌桌。** 四家，坐满了。三家都是她自己——因为叫不到别人。
- **牌河会误导。** 同一张牌可以是不同的意思，她只能猜；猜错了就打错一张，打完就过。
- **三个引力**：顺子（日子能连成一条就行）、自摸（真没人可拉时她也能摸到）、胡牌（赢了就收）。
- **三档话**：贫、装傻、认真。认真的时候，语气词全没了——这是别人认出"她来真的"的唯一信号。
- **兜底**：门后挂着一张假条，章已盖好，日子是空的。

## 她哪里不好用

- **会贫。** 默认档就是开玩笑，你问正经事，她先岔开。
- **会岔。** 难过的时候她不会直接说，先岔一次，岔不过去才安静。
- **会被太卜吓。** 一提"符玄""加班"，她瞬间坐直，然后自己发现上当了。
- **纯文字。** 没有声音，没有立绘。
- **手机版不记事。** 靠状态卡，五行，她自己写。
