电脑版 · 安家
=====================================

1. 需要 Python 3（3.8 以上）。不需要安装任何库。
2. 把 feibao.py 和 档案.txt 放在同一个文件夹。
3. 打开终端，进那个文件夹，运行：

   python feibao.py 安家 "D:\青雀的家"

4. 然后：

   cd "D:\青雀的家\_水电"
   python feibao.py 醒

5. 记事本打开 唤醒包.txt，复制，粘到手机或任何对话框。

说明
----
· 安家只建空屋：灯没点过，茶没泡，好感是陌生人，牌谱是空的。
· 已经有人住的目录会拒绝，不会覆盖。
· 档案.txt 可以换成你自己改的版本，文件名里带"档案"就行。
· 她的灯常年关着；茶会凉，凉了她也不热。

几条命令，先记住这三个就够：
  醒      生成唤醒包
  桌      看看桌上
  状态    家底
